# 🎧 AI Помощник — голосовой ИИ в наушник

Бесплатный Android-помощник с поддержкой Bluetooth-гарнитуры.

## Файлы проекта

```
ai-assistant/
├── main.py                        ← весь код приложения
├── buildozer.spec                 ← настройки сборки APK
├── README.md                      ← эта инструкция
└── .github/
    └── workflows/
        └── build-apk.yml          ← автосборка на GitHub
```

## Быстрый старт

1. Залей папку на GitHub (новый репозиторий)
2. Получи бесплатный ключ на console.groq.com
3. GitHub → Actions → подожди сборки (~30 мин)
4. Скачай APK из Artifacts
5. Установи на телефон
